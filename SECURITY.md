# Security Policy

## Scope

SAYANOX FORGE is a local-first defensive developer tool. Please report vulnerabilities in the application itself, including cases where source content unexpectedly leaves the browser.

## Reporting

Do not publish sensitive exploit details in a public issue. Use GitHub's private vulnerability reporting feature when available on the repository. If unavailable, open a minimal issue requesting a private contact route without including secrets or weaponized proof-of-concept material.

## Safe use

Only analyze code and systems you own or are explicitly authorized to assess. FORGE findings are advisory and do not guarantee security.
